¿Qué es CSS?

CSS (Cascading Style Sheets) es el lenguaje utilizado para definir la apariencia, el diseño y la presentación visual de un documento escrito en HTML. Permite aplicar colores, fuentes, espaciados y maquetaciones adaptables.

¿Qué aprenderé en este curso?

Aprenderás desde los fundamentos del Box Model y selecciones hasta técnicas avanzadas de maquetado con Flexbox y CSS Grid, animaciones, transiciones, diseño responsivo y preprocesadores como Sass.

¿Qué es CSS GRID?

CSS Grid es un sistema de maquetación bidimensional diseñado para la web. Permite dividir una página en regiones principales o definir la relación en términos de tamaño, posición y capa entre elementos HTML.
